# Parallel Programming and Performance Optimization

Contains a collection of parallel and heterogeneous computing projects implemented in C++ and CUDA, with a focus on performance measurement and scalability analysis.

Technologies used: C++ (Linux/POSIX), openMP (multithreading), MPI(distributed memory), CUDA (GPU programming), openCL (portable GPU programming), SIMD (SSE vectorization)

Projects:
OpenMP monte carlo simulation and k-means clustering with scalability analysis
SIMD (SSE) vectorized array multiplication and dot-product reduction
CUDA monte carlo simulation with thread block tuning
OpenCL quadratic regression over a 4 million point dataset
MPI based fourier analysis over a 1 million sample signal
